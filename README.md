# Om Dugane — Personal Portfolio

Responsive portfolio website built with HTML, CSS and vanilla JavaScript.

## Portfolio sections
- Profile introduction and portrait
- About, skills, education and experience
- Selected projects with repository links
- Certification and professional learning
- LinkedIn, GitHub and email links
- Contact form (opens a visitor's email client)
- Dark/light theme, project filters, responsive navigation
- Print-ready résumé view (browser Print → Save as PDF)

## Run locally
Open `index.html` in a browser. No build step is required.

## Before sharing publicly
1. Verify every personal detail, internship status, certification title/date, project description and external URL.
2. The résumé button uses the browser's print dialog. Choose **Save as PDF**.
3. The contact form uses `mailto:`; the visitor must send the email from their own email application. It does not deliver messages to a server.
4. Replace any social/profile URL if your profile address changes.
5. Check GitHub Pages under **Settings → Pages** and confirm a successful deployment before using the live URL on applications.

## Deployment
This is a static website and can be hosted with GitHub Pages. GitHub Pages expects an `index.html` file in the selected publishing source. See [GitHub Pages documentation](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site).
