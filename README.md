# Om Dugane — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Sections
- Hero section with portrait and résumé download link
- About, skills, experience and education
- Selected projects with repository/live links
- Contact section with a mailto-based contact form
- Responsive mobile navigation

## Run locally
Open `index.html` in a browser. No build step is required.

## Personalise before sharing
1. Replace the placeholder LinkedIn URL with your exact profile URL.
2. Add your approved résumé as `resume.pdf` in the repository root (the download button is already linked).
3. Review the profile text, project descriptions and skills for accuracy.
4. The contact form opens the visitor's email application; it does not submit to a server. For server-side delivery, connect a trusted form backend.

## Deploy
Enable GitHub Pages in **Settings → Pages**, select the `main` branch and `/(root)`, then save.
